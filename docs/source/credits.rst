Acknowledgments
===============

The methodology builds on published work on seismic wave propagation and on
microseismic monitoring network design, in particular:

* :cite:t:`AkiRichards2002` for the far-field radiation of a point moment-tensor source,
  the radiation-pattern convention and the free surface boundary condition;
* :cite:t:`Cerveny2001` for ray theory and the global absorption factor;
* :cite:t:`Kanamori1977` for the moment magnitude scale;
* :cite:t:`EisnerGeiEtAl2013` for the peak frequency of direct waves;
* :cite:t:`BooreBoatwright1984` for the average body-wave radiation coefficients;
* :cite:t:`Hallo2012` and :cite:t:`HalloEisner2013` for monitoring network sensitivity
  and the influence of the double-couple source model.

PyNetDesign stands on the open-source scientific Python ecosystem, and the author is
grateful to the developers of `NumPy <https://numpy.org/>`_,
`Pandas <https://pandas.pydata.org/>`_, `Matplotlib <https://matplotlib.org/>`_ and
`cmcrameri <https://pypi.org/project/cmcrameri/>`_, as well as to the
`Sphinx <https://www.sphinx-doc.org>`_ project and the
`PyData Sphinx theme <https://pydata-sphinx-theme.readthedocs.io>`_ used to build this
documentation.
